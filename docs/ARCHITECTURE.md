# Track — Architecture: the full file table

The complete table of active files — what each one is responsible for, what it pins and
why — and the cache-busting rule with the current `?v=` values. Moved out of `AGENTS.md`
on 2026-11-10, word for word, because `AGENTS.md` is loaded into every agent session and
had reached 174KB. `AGENTS.md` keeps a one-line map; **read a file's row here before
editing it**, and update the row here when its responsibility changes.

---

There is currently no package-managed build system.

Repository-local scripts and stylesheets are loaded from `scripts/` and `styles/` with a `?v=N` cache-busting query (`styles/styles.css?v=26`, `scripts/schema.js?v=11`, `scripts/calendar-core.js?v=14`, `scripts/firebase-sync.js?v=2`, `scripts/storage-guard.js?v=2`, `scripts/notes-core.js?v=4`, `scripts/notes-widget.js?v=8`, `scripts/journey-core.js?v=2`, `scripts/journey-book.js?v=2`, `scripts/true-storage-core.js?v=3`, `scripts/source-dump-core.js?v=2`, `scripts/graph-layout.js?v=1`, `scripts/doc-table-core.js?v=4`, `scripts/schedule-paste-core.js?v=2`, `scripts/quest-core.js?v=2`, `scripts/milestone-core.js?v=3`, `scripts/goal-core.js?v=1`, `scripts/project-core.js?v=2`, `scripts/strat-core.js?v=2`, `scripts/mm-tree-core.js?v=2`, `scripts/kolb-core.js?v=1`, `scripts/files-core.js?v=3` (in `sir-ks02.html` and `true-storage.html`), `scripts/file-store.js?v=2` and `scripts/files-view.js?v=3` (these two only in `true-storage.html`'s `FILES_SCRIPTS` list), `scripts/note-to-self-core.js?v=2`, `scripts/note-to-self.js?v=2`, `scripts/theme.js?v=1`, `scripts/viewport.js?v=2`). There is no build step to hash filenames, so this query is the only thing guaranteeing a returning visitor gets a changed asset instead of its cached copy. Bump the integer in every page that loads the file whenever its contents change, and keep the value identical across pages. **Every repository-local asset now carries one**; `theme.js` was the last exception and lost it when the appearance became a joint contract between the script and the stylesheet, where a stale script against fresh CSS is exactly the failure the query exists to prevent. The five iOS home-screen icons (`assets/icons/<page>-180.png?v=1`, one per page) carry one too; iOS caches a touch icon hard, so a re-rendered PNG needs its page's integer bumped. The one asset no page loads is `scripts/journey-fonts.js`: `journey-book.js` loads it, so its integer is `FONTS_V` in that file — a regenerated copy replacing a deployed one bumps `FONTS_V`, and therefore `journey-book.js`'s own `?v=` on the five pages.
